4. HTML FORM FIELD MAPPING STRATEGY:

The documents use a SOAP/XML WebService approach, but the Portale dell'Automobilista 
likely presents these as HTML forms. Key mapping points:

Input Fields (from HTML forms):
1. Demographics section:
   - <input name="nome"> → nome
   - <input name="cognome"> → cognome
   - <input name="dataNascita"> → dataNascita (format: YYYY-MM-DD)
   - <input name="codiceFiscale"> → codiceFiscale
   - <input name="sesso"> → sesso (F/M)
   - <select name="provincia">/@luogo_nascita_provincia → luogoNascita/provinciaNascita
   - <input type="file" name="foto"> → foto (base64 encoded)
   - <input type="file" name="firma"> → firma (base64 encoded)

2. Residence section:
   - <input name="provincia_residenza"> → provinciaResidenza
   - <input name="comune_residenza"> → comuneResidenza
   - <input name="toponimo"> → toponimoResidenza (VIA, PIAZZA, etc.)
   - <input name="indirizzo"> → indirizzoResidenza
   - <input name="civico"> → civicoResidenza
   - <input name="cap"> → capResidenza

3. License/Category section:
   - <select name="categoria_richiesta"> → categoriaRichiesta
   - <select name="categoria_disponibile"> → categoriaDisponibile
   - <input type="checkbox" name="cambio_automatico"> → cambioAutomatico

4. Payment section:
   - <select name="tipo_pagamento"> → tipologiaPagamento
   - <input name="codice_pagamento"> → codicePagamento
   - <input name="bollettino"> or <input name="cig"> (depending on tipo)

5. Medical section (if applicable):
   - <input name="protocollo_certificato"> → protocolloCertificatoMedico
   - <select name="medico"> → codiceIscrizioneAlboMedici
   - <input name="data_visita_medica"> → dataVisitaMedica

6. Operational/Admin:
   - <input type="hidden" name="marca_operativa"> → marcaOperativa
   - <input type="hidden" name="codice_operatore"> → codiceOperatore
   - <input type="hidden" name="uff_operativo"> → uffOperativo


5. SCRAPING PRIORITIES FOR GESTIONALE:

HIGH PRIORITY (Core booking functionality):
1. marcaOperativa, codiceOperatore, uffOperativo (authentication/context)
2. Applicant full demographics (AnagraficaRichiedenteType)
3. Residence/recapito (delivery address)
4. Requested category and available categories
5. Payment method and code
6. Medical certificate info (if in path)
7. Booking state and dates
8. Technical prescriptions list

MEDIUM PRIORITY (Useful for management):
1. Digital photo code
2. CQC/previous license info
3. Course data (for CQC)
4. Validity periods
5. Annotations/restrictions list
6. Special license plates
7. Medical visit dates
8. CML medical visit flags

LOW PRIORITY (Optional/Reference):
1. Timbro (stamp info)
2. Anomalies list
3. Document output references
4. Detailed audit dates/operators
5. Recovery credit info
