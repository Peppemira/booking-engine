12. TECHNICAL RESTRICTIONS - elencoPrescrizioniTecniche
================================================================================

Common prescriptions (by category):

General Restrictions:
- CAMBIO_AUTOMATICO    | Automatic transmission only
- OCCHIALI_DA_VISTA    | Corrective lenses required
- PROTESI_ACUSTICA     | Hearing aid required
- PACEMAKER            | Pacemaker present
- LIMITAZIONI_FISICHE  | Physical limitations (detailed)

Category-specific (e.g., for trucks C/D):
- VELOCIMETRO          | Speed limiter required (often for C/D)
- TACHIGRAFO           | Tachograph required
- RIMORCHIO_LIMITATO   | Trailer restrictions


================================================================================
SCRAPING IMPLEMENTATION NOTES
================================================================================

1. CASCADING FIELD DEPENDENCIES:
   - Payment Type (tipologiaPagamento) → determines which WS to call
   - Medical Data presence → determines if medical certificate WS variants used
   - Category selection → determines available date slots for exam
   - Birth date + category → determines validity period calculation

2. DATE FORMATS:
   - All dates must be YYYY-MM-DD format (ISO 8601)
   - Extract from HTML <input type="date"> or parse text inputs

3. SPECIAL CHARACTERS & ENCODING:
   - Italian characters (accents, umlauts) must be properly encoded
   - Use UTF-8 encoding for all text fields
   - File uploads (photo/signature) → Base64 encode to XML

4. FILE UPLOADS (foto, firma):
   - Must be JPEG format
   - Dimensions per ICAO guidelines
   - File size limits typically 100-500KB
   - Convert to Base64 string in XML

5. VALIDATION BEFORE SCRAPING:
   - Codice Fiscale: exactly 16 chars
   - Phone: various formats, extract digits
   - Postal code: exactly 5 digits
   - Birth date: validate against current date
   - Categories: validate against allowed list

6. STATE MACHINE FOR BOOKING FLOW:
   New Request → Demographics → Residence → Payment → Submit → Payment Processing
   → ACQUISITA (success) or RIFIUTATA/PAGAMENTO_DA_RIPETERE (failure)
   → Modification possible in certain states
   → Cancellation possible before PAGAMENTO_COMPLETATO

7. CRITICAL FIELDS NEVER OMIT:
   - marcaOperativa (identifies operator/school)
   - codiceOperatore (authentication)
   - uffOperativo (office context)
   - cognome (surname - required by Italian law)
   - dataNascita (birthdate)
   - datiResidenza (residence address)
   - tipologiaPagamento (payment method)
