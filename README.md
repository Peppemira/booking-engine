# Tutor vocale – esame mediatore marittimo

Ramo separato dal booking engine: contiene solo la pagina statica `index.html`
del tutor vocale per l'esame orale di abilitazione a mediatore marittimo
(domande lette a voce, risposta dal microfono, correzione parlata).

Pubblicata con GitHub Pages dal workflow `.github/workflows/pages.yml`.
`vercel.json` disattiva i deploy Vercel per questo ramo.
